## The line

> Our boss renamed the weekly status meeting 'Sync', so now we waste the same hour, just better branded.

## How it works

`main.ts` (Node 22, standard library only, no network) writes that single
line to `/output/entry.txt`, deterministically — every run produces the exact
same bytes.

```sh
node main.ts
cat /output/entry.txt
```
